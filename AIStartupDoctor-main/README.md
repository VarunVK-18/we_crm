## Startup Doctor – Monorepo

This repository contains three applications:

- `backend/`: Node.js/Express API with MongoDB (Mongoose)
- `frontend/`: React 18 + TypeScript SPA for end-users
- `admin/`: React 18 + TypeScript SPA for administrators

For comprehensive documentation, see `docs/README.md`.

### Quick Start

1. Configure environment variables as described in `docs/setup.md`.
2. Install dependencies in each subproject.
3. Run each app in separate terminals (`backend`, `frontend`, and `admin`).
